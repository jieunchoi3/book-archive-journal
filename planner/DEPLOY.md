## Not the diary app

The repo root is **Reading Archive** (`book-archive-journal` project → `book-archive-journal.vercel.app`). Diary and Relations live only on **weeklyplanner** URLs above.

## If the UI looks stale

Hard refresh (`Cmd+Shift+R`) or remove a saved Dock/PWA shortcut and open the URL again. An old alias can point at an outdated deployment until it is reassigned.
